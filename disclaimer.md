# Disclaimer

MMA is a graphical front end in the spirit of [mov-cli](https://github.com/mov-cli/mov-cli). Like mov-cli, it does not host, upload or store any video. The catalog comes from Stremio's public Cinemeta service, and streams come from third-party websites that MMA has no control over. The worker only passes them along to your browser.

You are responsible for what you watch and for following the laws where you live. If you run your own copy of the worker, you are responsible for how it is used. Check the terms of Cloudflare and GitHub before you put a copy online for other people.

If you own content that shows up through MMA, contact the site that hosts it. Removing it there removes it from MMA too.
